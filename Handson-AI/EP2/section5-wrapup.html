Three Takeaways

1. ADK 2.0 is a graph model

SequentialAgent, LoopAgent, AgentTool compose real orchestration workflows. before_model_callback lets you go fully deterministic without leaving the framework.

2. Skills encode opinions · MCP surfaces live data

The mapping skill calls MCP tools — they're complementary layers. Financial modeling skills prove it: same API, different behavioral rules. MCP can't give you that.

3. A2UI makes agents accountable

18 primitives, two-pass validation, streaming to the frontend in real time. The UI is part of the agent's output contract, not an afterthought.
