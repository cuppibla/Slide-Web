What Is a Skill?

SKILL.md

The instruction contract — what the LLM reads. When to use it, what tools are available, what order to call them.

tools.py

The implementation — actual Python functions the LLM calls. Executes in the agent process.

Two Skill Locations
LocationScope
agents/skills/Shared — every agent
agents/<agent>/skills/Local — one agent only

Local overrides shared on name collision

Key rule: Skills are loaded ON DEMAND — the LLM doesn't see tools it doesn't need this turn

Per-Agent Skill Scoping

Each sub-agent in the graph gets ONLY the skills it needs

pre_race agent
prepare_simulation spawn_runners
start_collector fire_start_gun
tick agent
advance_tick check_race_complete
post_race agent
compile_results stop_collector
Why Scoped, Not Shared?
  • No cross-contamination — tick can't call spawn_runners
  • Lean context — each agent pays only for what it uses
  • Least privilege — reduces LLM tool confusion
  • Composable — graph model + skills = scoped capability
# Each sub-agent: own skill scope

    "preparing-the-race")

    "advancing-race-ticks")

    "completing-the-race")

How Skills Are Discovered

agents/utils/__init__.py → load_agent_skills()

1. Scan agents/skills/ → shared skills
2. Scan agents/<agent>/skills/ → local skills
3. Merge by name — local wins on collision
4. Combine all tools from both directories
5. Return (skills, tools) → SkillToolset
Discovery Details
  • Each subdirectory with SKILL.md = one skill
  • load_skill_from_dir() → ADK's native Skill loader
  • importlib dynamically imports tools.py
  • If __all__ defined → use verbatim (re-export)
  • Otherwise → __module__ heuristic
Drop a directory with SKILL.md + tools.py into the skills folder. Next run, it's auto-discovered. No registration, no rebuild.
