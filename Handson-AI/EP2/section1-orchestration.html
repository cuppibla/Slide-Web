ADK 2.0 Agent Primitives

Graph nodes, not LLM wrappers — the graph IS the control flow

LlmAgent

Calls the model. Has instructions, tools, callbacks, session state.

Use for: reasoning, synthesis, adaptive responses

SequentialAgent

Runs sub-agents in order. No LLM routing — pure pipeline.

Use for: known ordered sequences

LoopAgent

Repeats sub-agent until condition met or max_iterations reached.

Use for: race ticks, retries, polling

ParallelAgent

Runs sub-agents concurrently. All execute simultaneously.

Use for: independent data gathering

Simulator Agent Graph

agents/simulator/agent.py

LlmAgent("simulator") ← root router
verify_plan() ← cheap
AgentTool → SequentialAgent("pipeline")
pre_race → parse, spawn, fire
LoopAgent("race_engine") → max 200 ticks
tick → advance + check
post_race → compile results
Key Insight

Despite being LlmAgents, pre_race and tick never call the LLM. before_model_callback intercepts every invocation.

Composition Pattern
  • Root routes via LlmAgent
  • Pipeline runs via SequentialAgent
  • Ticks iterate via LoopAgent
  • AgentTool bridges the two levels

AgentTool — Composing Sub-Graphs

agents/simulator/agent.py line 522

# Root agent sees pipeline as a tool
tools=[
    verify_plan,
    AgentTool(
        agent=pipeline,
        skip_summarization=True,
    ),
]
Why skip_summarization?

Without it, ADK asks the model to summarize the pipeline output before returning. The root agent just relays — no summary needed.

AgentTool Bridges Two Levels
  • Parent: LlmAgent that reasons and routes
  • Child: SequentialAgent with pure execution
  • Interface: same tool-calling API for both
Reexecution Guard

before_tool_callback prevents the pipeline from running twice per session. On Agent Engine, the root model's while-loop can re-invoke it.

runner_autopilot — 113 Lines, Zero LLM

agents/runner_autopilot/agent.py

def get_agent():
    agent = get_base_agent()
    agent.name = "runner_autopilot"
    agent.before_model_callback \
        = autopilot_callback
    agent.generate_content_config = \
        GenerateContentConfig(
            temperature=0.0,
            max_output_tokens=1,
        )
    return agent

agents/runner_autopilot/autopilot.py — dispatch table

# Pure function dispatch
HANDLERS = {
    START_GUN:        handle_start_gun,
    CROWD_BOOST:      handle_crowd_boost,
    DISTANCE_UPDATE:  handle_distance_update,
    HYDRATION_STATION:handle_hydration,
    TICK:             handle_tick,
}

Each handler: (state, data) → LlmResponse
The callback ALWAYS returns — model is never invoked. 293 lines of deterministic logic.

The agent boundary is about interface, lifecycle, and observability — not about whether an LLM is running inside.
