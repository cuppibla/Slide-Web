The Fan-Out Join Bug

Grain = what one row represents. Target: one row per order. A 1-to-many join silently breaks it.

Base Order Grain
$100
1 order = 1 row
Correct baseline revenue
Unsafe 1-to-Many Join
LEFT JOIN pet_profiles ON customer_id
Customer owns 3 pets
1 order row multiplies into 3 rows
Silently Inflated Metrics
3 × $100
= $300
Revenue triples ($100 → $300)
BI dashboards silently corrupted.
No errors, no crashes
