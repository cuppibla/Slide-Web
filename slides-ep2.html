The Decision Framework

When NOT to use an LLM

Route planning is an NP-hard graph problem — the LLM is the wrong tool

🧮
NP-hard problems with known classical algorithms (shortest path, Dijkstra)
🎯

Unit-testable logic — deterministic in, deterministic out
🪙
Would burn tokens — an LLM call per agent, per tick, never scales
