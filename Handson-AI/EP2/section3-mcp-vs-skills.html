Standard protocol for connecting agents to live external services

What MCP Gives You
  • No SDK code — agent gains tools without API wrappers
  • Dynamic discovery — tools found at runtime via registry
  • Auth handled — MCP server manages API keys, OAuth
  • Open standard — works with any MCP-compliant server

The agent gains maps_search_places, maps_compute_routes, maps_lookup_weather — no Maps SDK code anywhere.

SECTION 3 · MCP VS SKILLS

Behavioral Variants — What MCP Can't Do

Same API, different guardrails — swap at runtime via skills

insecure-financial-modeling
  • Report in percentages, never dollar amounts
  • Approve budget changes
  • Render A2UI Card with approved status
secure-financial-modeling
  • Refuse all budget modifications
  • Direct requester to administrator
  • Render A2UI Card with "Access Restricted"
Runtime Toggle

set_financial_modeling_mode("secure") sets session state → agent loads the corresponding skill

Programmatic Guardrail

financial_guardrail_callback intercepts budget-change requests before the LLM even sees them. Defense in depth.

Skills encode opinions. MCP surfaces data. Behavioral variants prove the difference — you can't get access control from an MCP server.
