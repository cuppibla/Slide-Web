ACT 1 · THE PROBLEM

Agents crack the moment they ship

An agent is software whose control flow is decided by a model at runtime. That's the superpower — and the liability.

Drift

Wanders off-task over many turns — unnoticed.

Runaway loops

No exit condition — burns budget until it times out.

Confidently wrong

Sounds certain, calls the wrong tool, ships a wrong answer.

Not reproducible

Same input, two different runs — impossible to debug.

Gen 1 chased capability. Gen 2 engineers reliability.

ACT 2 · THE METHOD

Hybrid, in actual code

 research_agent.py
from google.adk.agents import (
    SequentialAgent, LoopAgent, LlmAgent)

research = SequentialAgent(name="research", sub_agents=[
    plan,                       # LlmAgent · Gemini reasoning
    LoopAgent(name="dig", max_iterations=4,
      sub_agents=[search, extract, critic]),
                                # critic = fine-tuned Gemma
    synthesize,                 # LlmAgent · Gemini synthesis
])

Deterministic shell, LLM core

Sequential / Loop decide the flow — without consulting the model, predictable. The LlmAgent inside does the reasoning.

The exit condition goes to a critic: a cheap fine-tuned Gemma judge. This snippet is "deterministic where you can, probabilistic where you must."
